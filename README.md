# Автоматизация обработки хаотичных запросов (Скиллтон)

Проект реализует автоматический разбор неструктурированных входящих заказов клиентов на производство клееного бруса с использованием локального ИИ-стека.

## 💻 Технологический стек
- **Оркестрация и воркфлоу:** n8n (локальный сервер)
- **ИИ-платформа:** LM Studio (Локальный API-сервер, порт 1235)
- **LLM:** Qwen2.5-Coder-7B-Instruct (GGUF, квантование Q4_K_M)
- **Аппаратное ускорение:** NVIDIA RTX 4070 (Полный GPU Offload)

## 📐 Архитектура решения
1. **Входная точка:** Нода `Webhook (POST)` принимает сырой текст заказа в параметре `order_text`.
2. **Обработка данных:** Нода `HTTP Request` формирует структурированный запрос к локальному серверу LM Studio. Используется комбинированный промпт (`system` инструкция по парсингу + `user` данные).
3. **Валидация:** Нода `Code (JavaScript)` обрабатывает текстовый ответ модели, очищает его и парсит в строгий формат JSON.
4. **Вывод:** Нода `Respond to Webhook` возвращает результат вызывающей стороне.

## 📊 Пример работы системы
### Входящий сырой текст заказа:
"Привет! Нам нужен брус сосновый 40х60х2400 в количестве 108 шт. Сделайте побыстрее к 20 числу, пожалуйста!"

### Выходной валидный JSON-ответ:
```json
{
  "items": [
    {
      "name": "Брус",
      "width": 40,
      "height": 60,
      "length": 2400,
      "quantity": 108,
      "material": "Сосна/Ель",
      "comment": "Сделайте к 20 числу"
    }
  ],
  "questions": [
    "Уточните, пожалуйста, материал бруса (сосновый или ель)?"
  ]
}
